# 素材与字体

## Pixso 资源

照片、公司标志、合作伙伴图和 Hoob 标志直接来自用户提供的 Pixso 文件 **Hoob - Job Finder Website UI Kit**。`design-manifest.json` 记录了业务画板和主要导出素材的节点 ID。

`assets/images/` 为实际运行资源；`docs/screenshots/design/` 为原稿参考截图，不打包进应用。网页原稿的组件被重新实现为 Flutter 控件，业务页面没有用整张截图替代。

使用这些资源发布产品时，应根据原设计文件及相关品牌的许可条件确认可用范围。本项目未另行从图库抓取照片。

## 字体

基础字体为 Google Fonts 仓库中的 Red Hat Display，许可文件保留在 `assets/fonts/OFL.txt`。

来源：https://github.com/google/fonts/tree/main/ofl/redhatdisplay

为减小体积并避免 Windows 测试环境的字体回退问题，交付字体包含 400、700、800 三个静态字重，衍生字体内部名称为 **Hoob Display**，加入应用使用的箭头与四角星几何字形。应用中的 `RedHatDisplay` 是 Flutter 的本地字体别名。

没有运行时在线字体请求。
