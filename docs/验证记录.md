# 验证记录

## 环境

- Windows；Flutter 3.47.7 stable，Dart 3.13.5。
- Android 宿主工程、iOS 宿主工程及 Web 入口已提供。
- 业务数据为本地示例，无需服务端配置。

## 自动验证

`flutter analyze --no-pub`：通过，无问题。

`flutter test --no-pub --reporter expanded test/app_test.dart`：最终一轮 **6 组全部通过，15 秒**。常规验证与截图导出通过 `CAPTURE_SCREENSHOTS` 开关分开运行。

| 测试组 | 验证内容 |
| --- | --- |
| 全页面渲染与截图 | 14 个原稿对应界面、补充公司详情、职位筛选面板；无 Flutter 布局异常 |
| 搜索、筛选与收藏 | Mailchimp 搜索结果、无匹配空状态、Design 类别筛选、收藏写入及恢复 |
| 申请流程 | 空姓名、无效邮箱校验；模拟简历选择；成功保存；跳转及个人面板记录；重建状态后恢复 |
| 屏幕适配 | 全部页面在 320 × 740 下无布局溢出，含筛选面板；1280 × 900 桌面及 768 × 1024 平板渲染 |
| 档案与联系草稿 | 投资档案保存、重新打开恢复；联系表单保存及重新进入恢复 |
| 内容交互 | 公司关键词搜索、下拉筛选重置、文章类别过滤、FAQ 展开 |

测试的文件选择器使用模拟实现，未向系统文件对话框投递真实文件。该测试验证表单与文件选择结果的衔接；真实 Android／iOS 文件对话框仍需在设备上验收。
